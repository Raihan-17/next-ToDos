A modern, responsive Todo application built with **Next.js 16**, **Redux Toolkit**, **TypeScript**, and **shadcn/ui**.  
It supports full CRUD operations with modals, drawers, confirmation dialogs, and toast notifications.



 🚀 Features

 ✅ Fetch todos with pagination
 ➕ Add new todos (Modal)
 ✏️ Edit existing todos (Drawer)
 🗑️ Delete todos (Confirm Dialog)
 🔔 Success notifications using **Sonner**
 📱 Fully responsive (mobile-first)
 🎨 Modern UI with **shadcn/ui**
 ⚡ Optimized state management with Redux Toolkit
